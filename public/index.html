What are we posting about?

Paste an X post and it drafts a reply to it. Type an idea, or paste an article, and it drafts a post. One or the other, never both — say write a post about this over an X link if you want the post.

It reads the source, looks things up when that helps, and writes the way you write. Say read this and it takes the source in without drafting; say learn from this and it keeps what matters.
